# Mosaic Memory

A specification for a weighted vector relational memory system for AI agents:
semantic and episodic memories in a graph, recall by graph traversal with
chaining weights, emotional salience, multiplicative decay, and context-window
budgeting.

## Contents

- `memory-math.md` — the full specification: recall (Part I), the salience
  lifecycle (Part II), the context window (Part III), known inconsistencies
  (Part IV), and the sampling-seed appendix.

## A note on scope

This repository contains the **specification only**. The reference
implementation is not published here.

Examples in the spec come from two live agents, anonymized as Agent A and
Agent B; names, quotes, and personal details from their conversations are
left out or replaced.
